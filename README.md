# 🛡️ SecureHome

An AI-powered smart home surveillance system designed for real-time monitoring, intelligent threat detection, and low-latency edge-based security automation using Raspberry Pi and computer vision.

## 🌍 Overview

SecureHome is an intelligent home security solution built to provide continuous automated surveillance using embedded systems and AI/ML technologies.

The system enables users to:
- 🎥 Monitor surroundings in real-time
- 🧠 Detect threats using AI-powered object detection
- ⚡ Perform low-latency edge-based processing
- 🏠 Enhance home security through smart automation
